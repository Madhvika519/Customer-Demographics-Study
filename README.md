Project Overview

This project focuses on analyzing customer demographic data using Power BI. The dashboard provides insights into customer distribution based on gender, age, annual income, and spending behavior. The analysis helps businesses understand customer characteristics and improve marketing strategies.

---

Objectives

- Analyze customer demographic information.
- Study gender distribution among customers.
- Evaluate annual income patterns.
- Analyze customer spending behavior.
- Generate meaningful business insights through visualizations.

---

Tools Used

- Microsoft Excel
- Power BI Desktop
- GitHub
- Microsoft Word
- Microsoft PowerPoint

---

Dataset Information

The dataset contains customer records with the following fields:

- Customer ID
- Gender
- Age
- Annual Income (k$)
- Spending Score

---

Dashboard Features

- Total Customer Count
- Gender Distribution Analysis
- Annual Income by Gender
- Income vs Spending Score Analysis
- Customer Demographic Insights

---

Key Findings

- Female customers slightly outnumber male customers.
- Annual income varies across customer groups.
- Spending behavior differs among customers with similar incomes.
- Customer segmentation can assist in targeted marketing campaigns.

---

Conclusion

This project demonstrates how Power BI can transform raw customer data into meaningful visual insights for business decision-making and customer analysis.
